The assessed exercises are split into sections:

1. Basic Exercises: These are more concerned with the fundamentals of getting a specific interface, sensor, or actuator operating.
2. <debugHL>[Advanced Exercises](../AdvancedExercises/README.md)</debugHL>: These are more concerned with integrating the elements of the Basic Exercises into a working system, to achieve a goal. During the Advanced exercises you will also work with slightly more advanced programming concepts, such as implementation of a PI Controller and simple <debugHL>[finite state machines](https://en.wikipedia.org/wiki/Finite-state_machine)</debugHL>, (we will provide programming templates for both of these topics).



As discussed in the <debugHL>[Introduction document](../README.md)</debugHL>, This activity is split into several assessed exercises. This section describes the Basic Exercises, as follows:

- **Basic:** <debugHL>[LED Pattern](./ledPattern.md)</debugHL>
- **Basic:** <debugHL>[IR Sensor Measurement + Graph](./IrSensor.md)</debugHL>
- **Basic:** <debugHL>[Externally Powered Servo](./DriveServoMotor.md)</debugHL>
- **Basic:** <debugHL>[DC Motor](./DcMotor.md)</debugHL>
- **Basic:** <debugHL>[Encoders + Motor](./EncodeMotor.md)</debugHL>

You must complete, and have had marked, all of these exercises before you can gain credit for the <debugHL>[Advanced Exercises](../AdvancedExercises/README.md)</debugHL>.

A suggested timeline for achieving only the basic exercises is provided in the <debugHL>[introductory document](../README.md#Timeline)</debugHL>.

Each of these exercises will be assessed during the laboratory session, using the assessment structure outlined in the Appendix section of this document. When you have completed an assessed exercise, you should get your work marked one of the GTAs. 

!!! Warning
    **DO NOT leave all your exercises until the end of the 3rd laboratory session to get marked.** This may result in you running out of time to get your work marked within the allotted time, and you ***will*** lose marks. Instead, you should get your work marked as you complete each assessed exercise.
